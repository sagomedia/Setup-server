# 💡 Experiment: Sago 24/7 Home Server Stack
**Date:** 2026-09-01  
**Goal:** Build and verify the 1-click Docker Home Server stack (Immich + Jellyfin + FileBrowser + Tailscale) before video recording and live demonstration.

## Input Context & Requirements:
- Turn any old laptop (e.g. 4GB RAM, Linux/Ubuntu or Windows with Docker) into a 24/7 private cloud.
- Replaces Google Photos (via Immich), Netflix/OTT (via Jellyfin), and Google Drive (via FileBrowser).
- Access anywhere over 5G without router port forwarding (via Tailscale).
- Must be rock-solid, easy to install via a single script, and leave existing host files untouched.
- Distribution Target: YouTube Long-Form + 3 Shorts/Reels + GitHub Open Blueprint.
